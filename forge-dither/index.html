Error Diffusion

each pixel decides alone, pushes its mistake to the next one

palette: 4 colors · Floyd-Steinberg · 280×280
Each pixel picks the closest color it can from a tiny palette and wrong. The difference — the quantization error — doesn't vanish. Floyd and Steinberg's idea: push it forward. Seven-sixteenths right, three-sixteenths down-left, five-sixteenths down, one-sixteenth down-right. No pixel knows the image. No pixel knows what color it should be. Each one just corrects its neighbor's mistake, and the cascade of corrections — the propagated error — is what produces the gradients, the soft transitions, the illusion of continuous tone from a handful of colors. The order isn't imposed; it diffuses.
