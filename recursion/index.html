Recursion

Start with a string. Apply a rule: replace every symbol with a new string. Apply the same rule again. And again. After n iterations, the string is exponentially long — but structurally ordered. It encodes a fractal.

Aristid Lindenmayer, 1968: a formal grammar for modeling biological growth. He was studying algae. The rules he wrote — F → F+F-F-F+F — weren't meant to be beautiful. They were meant to describe how cells divide and branches fork. The beauty was a side effect.

The order here is different from every other piece in the Forge. It doesn't emerge from interaction. It doesn't arise from energy minimization or pheromone trails or coupled oscillators. It comes from repetition itself. A single rule, applied to its own output, produces infinite complexity from finite information. The fractal is already in the rule — iteration just reveals it.

Each symbol is a turtle command: F = forward, + = turn right, − = turn left, [ = push state, ] = pop state (for branching). Change the angle, change the depth, pick a preset and watch a line become a snowflake, a dragon, a tree. The same rule, more iterations, more of what was already there.
