Stigmergy

An ant leaves the nest searching for food. It wanders. When it finds food, it picks some up and walks back — and on the way back, it deposits a chemical. Other ants don't see the first ant. They see the chemical. They follow it. Some reach the food, pick some up, and on the way back they deposit more. The trail strengthens. Shorter paths get reinforced faster — more round trips per unit time — and longer paths fade as the chemical evaporates.

No ant knows what a shortest path is. No ant communicates directly with another. The pheromone field is a shared memory that no individual carries — it lives in the environment, not in the ants. This is stigmergy, Pierre-Paul Grassé, 1959: agents that change their environment, and the environment that changes the agents. The order isn't in the ants, it isn't in the chemistry — it's in the feedback loop between them.

Marco Dorigo turned this into an optimization algorithm in 1992. Click anywhere to add food. Watch the colony converge on the nearest source first, then the next, then the next — without any ant deciding anything.
