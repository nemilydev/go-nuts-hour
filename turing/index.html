A tape of cells, a head that reads one symbol at a time, and a table of rules: if you're in state q reading symbol s, write symbol t, move L or R, go to state p. That's it. Alan Turing, 1936. Everything a computer can do, this machine can do — just slower. The programs here are small: unary addition, binary increment, palindrome checker, busy beaver. But the architecture is universal. Every program that has ever run, every computation that will ever happen, is a Turing machine wearing more memory and a faster clock. The order isn't in the tape — it's in the rules, and the rules are small enough to hold in your hand.
