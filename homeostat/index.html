Homeostat

Four units, each holding a value, each connected to the others with weighted lines. The connections push and pull — some excite, some inhibit — and the values drift. When every value stays inside its viable range, the system is stable.

When a value leaves its range, the system is unstable — and it rewrites itself. A random connection changes its weight. If that doesn't work, another connection changes. The system doesn't know what the right wiring is. It doesn't know what destabilized it. It just keeps changing itself until the values come home.

This is W. Ross Ashby's ultrastability, 1952: a system that adapts its own structure, not just its state. It doesn't reorganize toward a goal — it reorganizes until it stops failing. The stability that emerges was never designed. It was found. Click a unit to perturb it. Watch the system rewrite itself. Press Shatter to break everything at once.
